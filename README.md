# Task 1 — Sales Data Analysis

## Objective
Calculate sales metrics and analyze monthly trends, product categories, and regions.

## Dataset
`data/sales_data.csv` is a synthetic practice dataset created for this project, not real company data.

## Tools
Python 3, pandas, matplotlib.

## Run
Install dependencies with `pip install pandas matplotlib`, then run `python sales_analysis.py`.

## Deliverables
The script creates KPI metrics, monthly trends, category and region summaries as CSV files, plus three chart images in `outputs/`.

## Metrics
Revenue = Units Sold × Unit Price. Cost = Units Sold × Unit Cost. Profit = Revenue − Cost. Profit margin = Total Profit ÷ Total Revenue × 100. AOV is average revenue per order.

## Business summary
Use the generated output tables and charts to identify the highest-revenue category, strongest region, and months with higher or lower revenue. Base recommendations on the generated results.

## Limitations
This small synthetic dataset demonstrates a workflow and does not represent a real business.
